# Mockup source screens

Put one screen per project here, named after the project slug. Then run:

    python3 scripts/make-mockups.py

Any file here replaces the PDF crop for that project. Projects with no file keep their current crop.

| File name | Project | Screen type |
| --- | --- | --- |
| `sc-braga.png` | SC Braga | Phone |
| `stc-design-system.png` | stc Design System | Desktop or board |
| `stc-voting.png` | Demand Committee | Desktop |
| `ejar.png` | Ejar | Desktop |
| `my-orange.png` | My Orange | Phone |
| `budget.png` | Budget | Phone |
| `flash.png` | Flash | Phone |
| `bona.png` | BONA Invest | Phone |
| `otida.png` | Otida | Phone |
| `check.png` | Check | Desktop |
| `jinni.png` | Jinni | Phone |
| `egyptian-streets.png` | Egyptian Streets | Desktop |

- **Formats:** `.png`, `.jpg`, `.jpeg` or `.webp` all work.
- **Phone screens:** portrait, no device frame, around 1179 × 2556.
- **Desktop screens:** flat and full width, around 1440 × 900 or larger.
